Obsidian 手机端同步 · 操作手册

GitSync 方案 ｜ 不用 OAuth、不用生成令牌、不用装插件 ｜ 约 10 分钟

先做一件事：把之前那个 vault 和 obsidian-git 插件都放一边 你之前那次报错（文件名不能包含 \ / :），根源很可能就是 obsidian-git 插件—— 它的作者在官方 README 里写了：手机端"非常不稳定，我不建议在手机上用这个插件"。 本手册换用他推荐的 GitSync，不需要任何 Obsidian 插件。

1在 Obsidian 建一个「本地」空 vault

  1. 打开 Obsidian，进入仓库列表（左侧拉出菜单最下面）
  2. 点 Create new vault（新建仓库）
  3. 名字填 读书
  4. 把它里面的「Store in iCloud」关掉 ← 这一步是关键
  5. 创建后里面保持空的，什么都别放
为什么必须是本地、必须空 等下 GitSync 会把仓库内容直接倒进这个文件夹。vault 里有东西会被覆盖； 放 iCloud 里则可能因为同步机制打架。之前那个 iCloud 里的 vault 不用删，先放着。

2装 GitSync

App Store 搜 GitSync（图标是个绿色分支），或直接打开：
apps.apple.com/us/app/gitsync/id6744980427

免费。它是独立的 App，不是 Obsidian 插件。

3GitSync 首次引导

它问你你怎么选
欢迎页 Let's Go点它
怎么发现这个 App 的随便选，或跳过
Choose your focus选 Sync mode
Premium / 付费页跳过，我们用不到
要不要通知权限允许（它用来提示后台同步状态）
选认证方式不要选 OAuth，选 HTTPS / HTTP（有的版本叫 URL）
要用户名 / 密码？都留空——仓库已改成公开，公开仓库不需要认证
Author details（用户名 / 邮箱）填 zzproc 和你的 GitHub 邮箱

4克隆仓库

  1. 仓库地址填：https://github.com/zzproc/reading-vault.git
  2. 问「选一个目录克隆进去」→ 选第 1 步建的那个 vault：
    我的 iPhone → Obsidian → 读书
  3. 提示已存在内容、要不要覆盖 → 选覆盖
  4. 等它跑完（内容很小，几秒）

5打开 Obsidian 看一眼

切到 读书 这个仓库，应该能看到卡片和音频了。 如果看到的是空的，回 GitSync 点一下 Sync Now，再回 Obsidian 看。

6设成自动同步（可选，但强烈建议）

不设也能用 只是每次读之前，要先去 GitSync 点一下 Sync Now。设了就不用管了。
  1. 打开 iPhone 的 快捷指令 App（图标是个彩色方块叠方块）
  2. 底部切到 自动化 标签（不是"快捷指令"那个标签）
  3. 右上角点 ＋ → 新建自动化
  4. 触发器列表里找 App，点它
  5. 出现的 "App" 那一行点下去 → 搜索框输 Obsidian → 选中它
  6. 下面选 已打开（"已关闭"可以不选）
  7. 点 下一步
  8. 搜索框输 GitSync → 在结果里找 Sync Now → 点一下，它就加为动作了
  9. 把「运行前询问」关掉 ← 关键，不关的话每次都会弹窗问你"要不要运行"
  10. 右上角 完成
验证一下 回主屏，点开 Obsidian。GitSync 会弹一条通知说正在同步；回到 Obsidian，如果罗辑新推了卡片，就出现了。
第 4 步找不到 App，或第 8 步搜不到 GitSync 截个图给罗辑。iOS 版本不同，触发器和动作的位置会变——我按你实际看到的界面说。

卡住了怎么办

现象怎么办
OAuth 转圈 / "Safari 打不开该网页"这是 GitHub 登录页被墙（跟你之前能打开仓库页是两台不同服务器）。别用 OAuth，改用 HTTPS/URL + 留空凭据
它非要填密码才让继续截图给我，我给你一个只读的仓库令牌（比 OAuth 更稳）
克隆完 Obsidian 里还是空的确认你打开的是第 1 步那个本地 vault，不是 iCloud 那个
提示文件夹非空第 1 步没建干净。删掉那个 vault 重建一个空的
还是报 文件名不能包含 \ / :把 obsidian-git 插件彻底卸掉再试——GitSync 不经过插件
